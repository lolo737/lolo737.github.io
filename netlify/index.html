WEEEEEE transfer

File transfer whose links never expire. Re-upload a file with the same name and the link updates to the new version, with no old copies kept. Built because WeTransfer links expire after a couple of days. Send a file on Friday, update it that night, and the link has already died or points at the old version. Here the link stays the same and the file behind it can change, as long as the filename matches. It runs on top of a Swiss file-transfer service that does the heavy lifting and makes the cover pages look lovely. Styled like an Ibiza coffee-table book.
